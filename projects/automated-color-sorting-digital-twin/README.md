Automated Color Sorting Line — Digital Twin

Overview

This project consists of a simulated automated sorting line developed using Rockwell Automation Emulate3D, Studio 5000 Logix Designer, and SolidWorks.

The system identifies boxes based on their color and automatically routes them to their corresponding sorting stations using PLC-controlled pneumatic actuators. The digital twin provides a virtual representation of the sorting process, allowing the system's behavior and control logic to be demonstrated in a simulated industrial environment.

System Functionality

The sorting process follows these main steps:

Color identification: Each box is identified as one of six colors: green, yellow, red, blue, purple, or orange.

PLC-based decision-making: The control logic determines the appropriate sorting station based on the detected color.

Stopper activation: The corresponding stopper is actuated to position the box for sorting.

Pneumatic diversion: A pneumatic cylinder pushes the box toward its assigned output.

Automated sorting: The process routes boxes to their designated destinations according to the programmed control logic.
